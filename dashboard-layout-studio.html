Dashboard Layout Studio Help

What this tool does

Dashboard Layout Studio edits Hubitat dashboard layout JSON using a spreadsheet-like row and column model. It is designed for rearranging, copying, trimming, resizing, spacing, and saving dashboard tiles without hand-editing every tile coordinate.

Compatibility: Dashboard Layout Studio works only with v1 dashboard layouts from the built-in Hubitat Dashboards app. It is not compatible with Hubitat EZ Dashboards.

Basic workflow
  1. Load a dashboard from the hub, from a JSON file, or from pasted JSON.
  2. Select tiles, rows, columns, or a rectangular area on the grid.
  3. Use the toolbar to insert, delete, clear, move, copy, paste, resize, trim, or adjust spacing.
  4. Use Undo/Redo while experimenting.
  5. Review JSON or CSS if needed.
  6. Save to the hub, download a file, or copy the finished JSON to the clipboard.

The grid is not a live Hubitat dashboard. It is an editor for the layout JSON. Changes are applied to the working layout until you save or download them.

Loading and saving layouts

Connect To Hub
Discovers dashboards from the configured Hubitat hub. Layouts loaded this way keep their hub save target, so Save to hub remains available.
Gear beside Connect
Shows hub connection settings: hub IP address, dashboard app number, and access token.
Dashboard list
After discovery, choose a dashboard to load its layout into the editor.
Load file
Loads a JSON file as an offline layout. This is useful for editing backups, but it does not create a hub save target.
Paste dashboard JSON
Loads pasted JSON as an offline layout. Like file load, this does not create a hub save target.
Save
Opens save options: Save to hub, Download as file, or Copy to clipboard. Save to hub is available only when the active layout was loaded from the hub.
Important hub-save distinction

If you load a layout with the side panel file/paste tools, the tool treats it as offline JSON. If you instead load from the hub and then use the JSON editor to replace or edit the layout, the existing hub save target is preserved.

Selecting tiles, rows, columns, and areas

Click a tile
Selects the tile at that cell. Repeated clicks on the same overlapped cell cycle through the stack.
Ctrl/Cmd-click tile
Adds or removes a tile from the current tile selection. On overlapped stacks, repeated Ctrl/Cmd-clicks cycle through layers.
Alt-click tile
Selects the connected tile cluster at that cell.
Double-click tile/grid cell
Selects the connected tile cluster at that cell.
Drag on grid
Creates a rectangular selection. The Selection mode option determines which crossing tiles are included.
Ctrl/Cmd-drag grid
Adds the rectangular drag selection to the current tile selection.
Click row/column header
Selects that row or column as a line selection.
Drag row/column headers
Selects a contiguous row or column range.
Shift-click header
Extends the row or column selection from the previous header anchor.
Right-click grid/header
Opens a context menu for tile, empty cell, row, or column actions.
Selection mode
  • default: selects tiles located in the target area by their upper-left row/column.
  • incl partial: also includes tiles that start outside the target but cross into it.
  • excl partial: limits the result to tiles fully contained in the target.
  • only partial: selects only tiles crossing the target boundary; intended for clear-type cleanup work.

Toolbar buttons

The first toolbar group in the top row contains actions that operate on the current selection: tiles, rows, columns, or selected areas. The next top-row group contains whole-layout actions such as Trim and Spacing.

Select
Selects all tiles in the layout. This is the toolbar equivalent of Ctrl/Cmd+A.
Info
Shows tile id, position, size, hub device name when available, template/device details, and tile-scoped custom CSS for the selected tile.
Insert
For row/column selections, inserts rows or columns before the selected line range and shifts affected tiles.
Delete
Deletes selected rows/columns and shifts later tiles to close the gap. For tile selections, use Clear to remove without shifting.
Clear
Removes selected tiles or tiles in the selected area without shifting other tiles.
Move to
Starts a placement operation. Click a destination cell or compatible row/column header to move the selection.
Copy to
Starts a placement operation that duplicates the selection to a clicked destination.
Trim
Whole-layout action that removes blank space above and/or left of the current layout. Hold the button for top-only or left-only choices.
Resize
Selection-action button that sets selected tiles to an exact height and width. Options can preserve spacing between resized tiles and/or push the surrounding layout out of the way. When Overlaps is set to push, or Shift is held, the Resize button glows and the dialog opens with Preserve spacing between resized tiles and Push layout to make room enabled.
Spacing
Opens a dialog with all spacing actions: Set all, Set rows only, Set columns only, Unstack and Set All, Inc/Dec all, Inc/Dec rows only, and Inc/Dec columns only.
Enl/Rdc
Opens the Enlarge / Reduce dialog for enlarging or reducing the entire layout by row and column amounts. Positive rows/columns enlarge tiles; negative rows/columns reduce them. This is equivalent to selecting all tiles and dragging the lower-right resize handle.
Unstack and Set All
Set-menu option that is enabled only when tiles overlap. It breaks overlap stacks apart and sets spacing between individual tiles.
Spacing value
In the Spacing dialog, positive values increase spacing, negative values decrease spacing, and zero disables Inc/Dec while still allowing Set actions.
Cut / Copy / Paste
Uses an internal tile buffer. Cut keeps tiles visible until the first paste, which behaves as a move; later pastes create copies.
Undo / Redo / Undo All
Step backward, step forward, or restore the layout to the state it had when first loaded. For hub-loaded layouts, Undo All restores the hub-equivalent state and refreshes Rendered View instead of disabling it.
JSON
Opens the editable JSON editor for direct layout edits, formatting, load-file-into-editor, copy, download, and apply.
Save
Choose hub save, file download, or clipboard copy.

Move, copy, paste, overlaps, and spacing

Placement operations

Move to, Copy to, and Paste put the editor into a pending placement mode. After choosing the action, click the destination grid cell. Use Escape to cancel the pending operation.

Push behavior

Push is available for a single tile or a single connected cluster. It is disabled for disconnected multi-cluster selections or buffers. When push is used, tiles to the right and/or below the destination are moved enough to make room.

Overlaps: warn
Blocks operations that would overlap existing tiles.
Overlaps: allow
Allows the operation even if resulting tiles overlap.
Overlaps: skip
Skips conflicting copied/moved tiles when possible.
Overlaps: push
Moves affected tiles to make room, using the Push buf value as an added gap.
Dup CSS
When copying tiles, duplicates tile-scoped custom CSS for the new tile ids.
Spacing and unstacking

Spacing Set normally treats touching or overlapping tiles as connected clusters, so spacing is adjusted between clusters without breaking them apart. Unstack and Set All is available only when the layout has actual overlapping tiles. It treats every tile as its own unit, moves tiles as needed, and sets the requested spacing while removing overlaps. This is the GUI equivalent of using spacing set with overlap removal for all tiles.

Dragging and resizing

Drag selected tiles directly on the grid to move them. Drag the resize handle at the bottom-right of a selected tile to resize the selection. Mouse resizing grows from the upper-left corner and adjusts neighboring selected tiles to avoid growing over each other. The Resize dialog does the same kind of spacing-aware resize, but uses an exact height and width entered by the user. The Enl/Rdc (Enlarge / Reduce) dialog applies that same resize-drag behavior to the full layout by treating every tile as selected and applying row/column deltas.

Resize dialog options: Preserve spacing between resized tiles preserves the original spacing between the selected tiles while their sizes change. If the target size is larger than the selected tiles, the layout option is Push layout to make room: it automatically enables Preserve spacing between resized tiles and moves affected surrounding tiles to make room, using the same push buffer and overlap behavior as Move to, Copy to, and Paste. If the target size is smaller than the selected tiles, the option changes to Pull layout to close gaps. When Pull layout to close gaps is unchecked, unselected tiles do not move; only the selected tiles resize, though Preserve spacing between resized tiles can still move selected tiles relative to each other to preserve their internal gaps. When Pull layout to close gaps is checked, every row/column band freed by the shrink is removed from downstream tiles, so the collapse continues through the full layout rather than stopping at the first nearby row or column. When multiple selected tiles form one adjacent cluster with no unselected tiles between them, their internal spacing is preserved regardless of gap size, and the surrounding layout is pushed or pulled using the resized cluster's combined outside footprint. If an unselected tile sits between selected tiles, Resize Push/Pull is blocked instead of treating the selection as separate pieces. Without Push/Pull layout, conflicts are handled by the Overlaps setting: warn, allow, or skip. If the entered size enlarges any selected tile and would create overlaps, the Resize dialog shows a live warning. With Overlaps set to allow, the warning indicates that overlaps will be allowed. With Overlaps set to warn, pressing Resize opens a confirmation so the user can cancel or deliberately proceed creating the overlaps.

JSON editor and CSS tools

JSON editor
Allows direct edits, cut/copy/paste, formatting, downloading, copying, and loading a JSON file into the editor text area. The Copy button copies the visible editor pane as formatted plain text so line breaks and indentation paste correctly into tools such as Notepad.
custom field views
The customCSS, customHTML, and customJS buttons switch the editor to only that field. Edits sync back into the full JSON when you switch views, format, copy, download, or apply.
Validate / Format
Validates and formats the currently visible editor view. Full JSON is JSON-formatted; customCSS, customHTML, and customJS use very basic formatting and limited sanity checks. In customCSS view, the format step opens a review dialog when it finds duplicate selector/property declarations, conflicting declarations for the same selector/property, orphan tile rules, or selector rules that can be consolidated. Conflicts are grouped with value bubbles and the current cascade winner selected automatically, plus an Ignore choice for leaving a conflict group unchanged. You can also comment out discarded conflicting declarations instead of deleting them. Duplicates and consolidation choices are listed with preselected checkboxes so you can accept or skip each cleanup. Applying selected cleanup to the current working layout creates a normal Undo checkpoint. Compact CSS still controls the final compact one-rule-per-line output, split selector lists, condensed rule bodies, and CLI-like sorting, while preserving standalone and rule-body comments.
Apply changes
Validates and replaces the current working layout. JSON editor commits are normal edits and create an Undo checkpoint before the layout is replaced. If only a customCSS, customHTML, or customJS field view is committed, existing Rendered View captures are kept but marked as not reflecting those manual changes until refreshed. Full JSON edits still invalidate Rendered View captures. If the layout was loaded from the hub, the hub save target is preserved.
CSS status indicator
Appears when customCSS validation finds conflicts, duplicate declarations, orphaned tile rules, or selector consolidations. Green indicates optional cleanup suggestions, yellow indicates non-critical cleanup items such as orphans or duplicates, and red indicates CSS conflicts that should be reviewed. The cleanup dialog can remove selected items or preserve cleaned CSS as comments.
Tile-scoped CSS
Rules such as #tile-40, #tile_40, or .tile-40 are treated as tile-scoped CSS for copy/cleanup operations.

Use the JSON editor when you want to replace the layout while preserving hub context. Use side panel Load file/Paste JSON when you want to open an offline layout.

Hub connections unavailable

This page can only connect to your Hubitat hub when it is hosted by the hub itself. Browsers block cross-origin requests due to CORS (Cross-Origin Resource Sharing) restrictions, which prevent pages loaded from one location from accessing resources on another.

To enable hub connections:

  1. Open your Hubitat hub's web interface
  2. Go to Settings → File Manager
  3. Upload this HTML file to the hub
  4. Open the file from the hub (e.g. http://<hub-ip>/local/dashboard-layout-studio.html)

You can still use this tool offline by loading a dashboard JSON file using Load file… or Paste JSON.
